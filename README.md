## 🧭 How I like to work with data

```text
Start with a question
        ↓
Understand the data
        ↓
Clean, validate, and prepare it
        ↓
Explore patterns and test assumptions
        ↓
Use SQL / Python / statistics where they help
        ↓
Build useful metrics and visualizations
        ↓
Explain what the findings mean
        ↓
Share practical next steps
```

I try to keep the process honest: understand the question first, check that the data supports the analysis, and be clear about what the results can — and can't — tell us.

## 🧭 How I like to work with data

For most projects, my workflow looks something like this:

```text
Start with a business question
          ↓
Understand the data
          ↓
Clean, validate, and prepare it
          ↓
Explore patterns and test assumptions
          ↓
Use SQL / Python / statistics as needed
          ↓
Build useful metrics and visualizations
          ↓
Explain what the findings mean
          ↓
Suggest practical next steps
```

I try to keep the process simple: understand the question first, check that the data supports the analysis, and be clear about what the findings can (and cannot) tell us.
